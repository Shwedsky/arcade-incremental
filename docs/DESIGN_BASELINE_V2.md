# Design Baseline V2

Status: **APPROVED PRODUCT BASELINE**

This document persists the owner-approved concept decisions previously reviewed in Issues #1–#3.

## Core fantasy

Start as one person pushing a hand cart through dense salvage zones. Break junk in an arcade top-down loop, collect bursts of resources, return to a roofless garage, dismantle/process materials, build or buy machines, then grow through van -> worker -> hangar -> salvage yard -> industrial workshop -> processing plant.

## Locked design pillars

- Active control is movement + target choice; a valid nearby target is dismantled automatically.
- Scavenging must feel arcade-first: dense target fields, fast destruction, resource bursts, magnet pickup, visibly growing numbers and rare-component moments.
- Visual satisfaction matters more than realistic junk modeling.
- Offline begins at minute 1: baseline ~20% active efficiency with ~2h cap per absence.
- Workers improve parallel/offline throughput later; they do not unlock offline.
- First major machine: **Small Compactor Press**.
- Important machines normally have two acquisition routes:
  - buy ready-made: fast and expensive;
  - build: cheaper cash cost + raw materials + components + fabrication time.
- Early raw materials: **metal, copper, plastic**.
- Early components are intentionally limited to four:
  - bearings;
  - electric motor;
  - hydraulic unit;
  - electronic module.
- Additional components are introduced only with a new source, new zone and desirable recipe.
- First worker comes only **after the van**.
- Van target pacing: roughly **8–15 cumulative progression hours**.
- Major phase changes must alter what the player can physically collect/process, not only increase income multipliers.

## Combo philosophy

User-facing name: **Combo**.

Combo is not available at start and is not the first talent. It sits around the third meaningful node in the Salvage branch, targeted around 2–4 progression hours for a player deliberately investing into that branch.

Before Combo, early nodes are foundational upgrades such as dismantle speed. Combo then unlocks a new mechanic; later nodes extend grace time, stack cap, momentum and eventually a modest rare-component benefit.

Combo should improve rhythm and presentation, not create an uncontrolled direct money multiplier.

## Talent-tree rule

Each branch should broadly follow:

**1–2 foundational upgrades -> first new mechanic -> mechanic upgrades -> second strong mechanic -> late specialization.**

Branches:
- Salvage / dismantling;
- Logistics;
- Workshop;
- Automation / offline;
- Trade.

## Visual direction

- modern stylized 2D / light pseudo-2.5D top-down;
- no expensive realistic 3D world;
- simple readable character silhouette rather than detailed anatomy;
- compact dense scavenging maps rather than open world;
- roofless top-down garage/hangar;
- recognizable clickable machines;
- locked future machines visible as silhouettes/footprints with padlocks;
- machine panels show effect, Buy vs Build, missing materials/components, where to find them and shop fallback price.

## Current pacing target

These are design bands to validate mathematically, not final balance promises:

- 0–1.5h: hand cart / tiny garage / manual loop;
- 1.5–4h: working garage + first press;
- 4–8h: equipped garage + several processes;
- 8–15h: van;
- 12–20h: first worker, always after van;
- 18–30h: full garage / hangar becomes major goal;
- 28–50h: hangar;
- 45–80h: salvage yard;
- 75–120h: industrial workshop;
- 120h+: processing plant / true late game.

## Product principle

**The player should enjoy how junk explodes into value more than the realism of the junk itself.**
