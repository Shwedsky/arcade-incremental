# Arcade Incremental

Design-first repository for a long-term arcade incremental game about scavenging, dismantling, recycling and building an industrial salvage business.

## Current status

**Pre-production / design baseline approved. No gameplay implementation yet.**

Approved direction:
- arcade top-down scavenging with automatic dismantling of nearby targets;
- dense maps with satisfying destruction, resource bursts, magnet pickup and rising numbers;
- start with one person + hand cart + tiny roofless garage;
- offline progress from minute one;
- recognizable clickable machines in garage/hangar;
- machines can be bought ready-made or built from cash + resources + components;
- early resources: metal, copper, plastic;
- early components: bearings, electric motor, hydraulic unit, electronic module;
- first machine: small compactor press;
- van target around 8–15h cumulative progression; first worker only after van;
- long-term path: hand cart -> garage -> van -> worker -> hangar -> salvage yard -> industrial workshop -> processing plant.
