ARCADE INCREMENTAL — V3-B OWNER REVIEW

Запуск на Windows 10/11:
1. Полностью распакуйте ZIP в обычную папку.
2. Дважды щёлкните START_V3B.cmd.
3. Откроется браузер с локальной версией игры.
4. Не закрывайте окно launcher, пока тестируете игру. Для остановки нажмите Ctrl+C или закройте окно.

Python, Node.js, npm и Git для запуска НЕ нужны. Используется Windows PowerShell, входящий в Windows 10/11.

Если запуск не удался:
- окно НЕ должно исчезнуть молча: START_V3B.cmd покажет ошибку и остановится;
- подробности будут записаны в launcher-v3b.log рядом с START_V3B.cmd;
- проверьте, что рядом есть папка dist и файл dist\index.html;
- не запускайте файл прямо из окна ZIP — сначала распакуйте архив целиком.

Что тестировать в V3-B:
1. На поле подойдите к цели: над ней должны быть понятные HP / max HP, ваш DPS и подсказка по криту.
2. Во время разбора должны идти отдельные читаемые числа урона; крит должен отличаться визуально.
3. Найдите крупную кучу/крупную бытовую цель в Garage-зонах: после разрушения она должна распасться на реальные дочерние цели, которые тоже надо разобрать.
4. Добыча должна оставаться в тележке/транспорте и НЕ попадать на склад автоматически при возвращении домой.
5. На базе должен быть отдельный блок «ГРУЗ ВЫЛАЗКИ» и кнопка «Разгрузить на склад».
6. Только после нажатия этой кнопки сырьё и компоненты должны перейти на склад.
7. После разгрузки перезагрузите страницу: склад должен сохраниться, а груз вылазки оставаться пустым.
8. Продолжите собирать мусор: крупные кучи должны со временем появляться снова, а поле не должно становиться навсегда пустым.

Главный вопрос V3-B:
«Понимаю ли я руками, сколько у цели здоровья, насколько я силён, что именно везу домой и когда добыча действительно становится ресурсом бизнеса?»

V3-A тоже не должен сломаться: Overview, туман карты, туман дерева талантов и точный ETA персонала остаются частью сборки.


V3-B.1 VISUAL READABILITY — что проверить:
- Z1/Z2: крупная составная цель должна читаться именно как КУЧА/ЗАВАЛ из нескольких узнаваемых предметов, а не как один холодильник.
- После разрушения кучи дочерние цели должны выглядеть логичным продолжением исходного завала.
- Фон первой карты должен читаться как реальное место: дорога, огороженная свалка/двор, мастерская/гаражные боксы и ориентиры.
- Развитие: пять веток должны читаться как пять направленных дорожек сверху вниз, без ощущения круговой паутины/PoE.
- Карта зон должна читаться как последовательный маршрут с понятным следующим фронтиром.
