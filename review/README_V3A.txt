ARCADE INCREMENTAL — V3-A OWNER REVIEW

Запуск на Windows 10/11:
1. Полностью распакуйте ZIP в обычную папку.
2. Дважды щёлкните START_V3A.cmd.
3. Откроется браузер с локальной версией игры.
4. Не закрывайте окно launcher, пока тестируете игру. Для остановки нажмите Ctrl+C или закройте окно.

Python, Node.js, npm и Git для запуска НЕ нужны. Используется Windows PowerShell, входящий в Windows 10/11.

Если запуск не удался:
- окно НЕ должно исчезнуть молча: START_V3A.cmd покажет ошибку и остановится;
- подробности будут записаны в launcher-v3a.log рядом с START_V3A.cmd;
- проверьте, что рядом есть папка dist и файл dist\index.html;
- не запускайте файл прямо из окна ZIP — сначала распакуйте архив целиком.
